Stylish GUI, Interface, UI, GUI, Stylish

Interface alteration mod for Neverwinter Nights and Enhanced Edition.

Features:

- Retextured interface with new art style.
- Non-transparent dialogue window
- Colored class icons and status effects


Intallation:
------------

NwnEE: Copy "override" folder from archive to "Documents\Neverwinter Nights\"

Nwn: Copy override folder from archive to your NWN folder.

 

Changelog:
-----------------
Added updated version StylishGUI_EE, modified to work correctly with Neverwinter Nights Enhanced Edition,
since couple of files changed and new ones were added, updated transparency and changed main menu background,
removed blank zone loading screens, so you can see and use custom ones.

- 7 Nov 2020: Remade Party Bar panel and some inventory icons at higher resolution, will look better when using increased UI Scale.

- 8 Nov 2020: Fixed invisible spell level icons in lvlup panel.
