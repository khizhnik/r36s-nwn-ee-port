Hak version and also automated wizard installation version for NIT.

Created for fast installation, no override files.

Strongly suggested to install NIT  and manage the mod.

Neverwinter Nights Mod Installer Tool - NIT will automatically generate userpatch.ini though a userpatch.ini already included.

 

Post Installation Instructions - How to Run

  1. In game, turn on debug mode (Open console and enter DebugMode 1)
  2. Run the setup script (Open console and enter dm_runscript sw_override)
  3. Script will check for a valid classes.2da file and aborts with a message if invalid
  4. Script will run the update and add the spellbook to your inventory
  5. Add the spellbook item to your hotbar and use it to open the widget

All credits goes to NUI Spell Widget author Caladawn.
