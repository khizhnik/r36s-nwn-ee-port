First version of nui for character customization.

Supported appearance:
- Armor: https://youtu.be/kDCRXJMiYGE
- Body: https://youtu.be/Wlnvui7pxBQ
- Helmet: https://youtu.be/azTjlJIVbKs
- Shield: https://youtu.be/K2tvvCgOgHE
- Weapon: https://youtu.be/K2tvvCgOgHE

Hak:
- Contains images from https://amethyst-dragon.com/nwn/Images/colors_hair.htm


Scripts:
- lib_exp_* - examples (body, armor, helmet, shield, weapon)* NUI
-  lib_*_events - events for (body, armor, helmet, shield, weapon)* NUI
- lib_armor - NUI for armors
- lib_body - NUI for body 
- lib_helmet - NUI for helmet
- lib_shield - NUI for shield
- lib_weapon - NUI for weapon
- lib_client_enter - Module evet OnClientEnter

I think you can try implementing this yourself:

  1. Check how much gold the player has:

    • GetGold
    • HasGold

  2. Use the result to determine if the button should be active:

    • NuiEnabled

  3. If the player accepts the changes, deduct the gold:

    • TakeGoldFromCreature

However, make sure to lock the inventory or perform a second validation to prevent exploits.
