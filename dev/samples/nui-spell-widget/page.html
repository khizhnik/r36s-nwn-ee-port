A NUI widget that allows caster acces to their entire spellbook without a great deal of right clicking! It's very similar to the NWN2 widget spellcasters have access to. There are 2 separate flavors. The first is as an erf file that can be imported into a module. There is also an override version that can be used by players in existing modules. 

The override version is very much a use at your own risk kind of thing. I've done my best to avoid breaking anything, but the widget is very script heavy.

Installation Instructions - ERF version

  1. Import spell_widget.erf in to your module
  2. Open module properties (Edit -> Module Properties)
  3. Navigate to the Events tab
  4. Set the OnModuleLoad event to sw_mod_def_load or add the contents of it's main function to your custom script
  5. Set the OnPlayerLevelUp event to sw_on_plyr_lvl or add the contents of it's main function to your custom script
  6. Set the OnPlayerRest event to sw_on_plyr_rest or add the contents of it's main function to your custom script
  7. If you are using x2_mod_def_act as the OnActivateItem handler and haven't customized the tag based scripting system you can skip the next step
  8.  Set the OnActivateItem event to sw_mod_def_act or add the contents of it's main function to your custom script
  9. If you want to allow players to use the chat commands, set the OnPlayerChat script to sw_on_plyr_chat or add the contents of it's main function to your custom script
  10. Add the sw_it_mbook item to your spellcasting players using the method of your choice (triggers, merchants, client enter scripts)

 

Installation Instructions - Override versions

  1. Place the ncs and uti files in your override directory
  2. In game, turn on debug mode (Open console and enter DebugMode 1)
  3. Run the setup script (Open console and enter dm_runscript sw_override)
  4. Script will check for a valid classes.2da file and aborts with a message if invalid
  5. Script will run the update and add the spellbook to your inventory
  6. Add the spellbook item to your hotbar and use it to open the widget

 

Known Issues:

  • Spells that fail due to arcane spell failure or failed concentration checks may not correctly disable. This can be fixed simply by closing and reopening the widget.
  • Cleric spontaneous casting while the widget is open will cause the memorized spells to be off. It can fixed by closing and reopening the widget.

  • I have had occasional hard crashes when using the widget. I haven't been able to recreate this consistently and have been unable to nail down a cause.

Glad you're enjoying it. To answer your questions:

  • There is a spellbook item to open the spell widget, an orb to open the config widget and the placeable is part of a workaround for an issue where cleric domain AOE spells can't target a location when called from a script.
  • There  is no functionality changed in that script, I just got tired of the warning showing up because one of the function declarations didn't match the implementation.
  • If you have another script you need in one of those event handlers, you should just be able to add ExecuteScript(<script name>) at the end of your script. That is what the override version does when it finds an existing event handler for one of the events it needs.
